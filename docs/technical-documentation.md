# Technical Documentation

## Project Structure
- `index.html`: Main page structure and sections (About, Projects, Contact)
- `css/styles.css`: Styling and responsive layout
- `js/script.js`: Interactivity (theme toggle, greeting, smooth scroll, form message)
- `assets/images/`: Images used in the site
- `docs/`: Reports and documentation

## Features
- Responsive navigation bar and layout
- Projects grid that becomes 1 column on smaller screens
- Dark/Light theme toggle (saved in localStorage)
- Greeting message based on current time
- Contact form validation using HTML required fields + JS demo submit message

## How to Test
1. Open `index.html` in a browser.
2. Resize the browser window to test mobile/tablet/desktop.
3. Click navigation links to test smooth scrolling.
4. Toggle theme button.
5. Submit contact form and check the message.
